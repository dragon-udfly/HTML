# HTML Practice & Fundamentals Repository 🌐📄

A structured collection of HTML files, practice pages, and web assets designed to demonstrate core markup techniques, text formatting, and structural elements like tables.

---

## 📂 Repository Structure

```text
HTML/
│
├── src/
│   └── icon.png            # Static media icon asset
│
├── format.html             # Text formatting and styling practice page
├── main.html               # Primary landing or demo page
├── practice1.html          # Introductory HTML practice exercise
└── table.html              # Demonstrating HTML table structures and elements
```

## 🚀 Key Topics & Elements Covered
1. Document Structure: Standard semantic layout and organization (main.html, practice1.html).
2. Text Formatting: Utilizing standard markup tags for headings, paragraphs, and content styling (format.html).
3. Tabular Data: Structuring rows, columns, headers, and data cells using HTML tables (table.html).
4. Asset Integration: Incorporating static resources like images and icons (src/icon.png).
